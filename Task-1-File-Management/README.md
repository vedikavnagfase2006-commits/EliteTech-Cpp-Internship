# Task 1 - File Management Tool

## EliteTech Intern C++ Internship

### Objective
Create a C++ application that demonstrates file handling techniques.

### Features
- Write data to a text file
- Append data to a text file
- Read data from a text file
- Menu-driven interface
- Basic file error handling

### Technologies Used
- C++
- iostream
- fstream
- string

### File Operations

1. **Write to File** - Creates or overwrites the text file.
2. **Append to File** - Adds new data without removing existing data.
3. **Read File** - Displays the contents of the text file.

### Files

- `file_manager.cpp` - C++ source code
- `data.txt` - Text file used by the application
- `README.md` - Project documentation
